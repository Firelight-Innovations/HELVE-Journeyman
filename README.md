# Helve Journeyman

Game design software for the Helve stack — design prototyping and rough
playable systems. Expected to be a substantial standalone piece of the
stack.

This is a development tool; it does not ship with games built on Helve.

Status: pre-alpha, scaffolding only. Tech stack TBD.

Part of the [Helve](https://github.com/Firelight-Innovations/helve) stack.
